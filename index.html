איך להעלות דף זה ל-GitHub Pages בחינם?

דף זה נכתב כקובץ יחיד ועצמאי לחלוטין (Single File HTML). תוכלו לשמור אותו במחשב או בנייד ולהעלות אותו לשרת בחינם ב-3 צעדים פשוטים:

1

שמירת הקובץ

שמרו קובץ זה במחשב בשם המדויק: index.html

2

העלאה ל-GitHub

צרו מאגר (Repository) ציבורי חדש ב-GitHub וגררו אליו את הקובץ index.html.

3

הפעלת GitHub Pages

בהגדרות (Settings -> Pages) בחרו ב-Branch main ולחצו Save. תוך דקה האתר באוויר!
